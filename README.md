# McPvPTiers

PvP ranking website inspired by MCTiers.

## GitHub Pages Setup

1. Create a GitHub repository
2. Upload all files
3. Go to:
   Settings → Pages
4. Select:
   Deploy from branch
5. Choose:
   main / root
6. Save

Your site will go live in a few minutes.
